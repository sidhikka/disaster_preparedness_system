Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

Features

- Responsive and user-friendly interface
- Modern UI components
- Reusable and maintainable code
- Optimized frontend development
- Cross-device compatibility

Getting Started

To run this project locally, ensure that Node.js and npm are installed.

npm install
npm run dev
